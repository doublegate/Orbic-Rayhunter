# re/

Reverse-engineering notes for the Orbic RC400L firmware (REA, Ghidra, rizin).

Committed: methodology notes, function/symbol maps, offsets, scripts, hashes of analyzed
binaries, and short excerpts needed to explain a finding.

Not committed (gitignored): Ghidra projects (`re/ghidra/`), extracted firmware
(`re/extracted/`), and any binary taken from the device. See
[docs/RE-METHODOLOGY.md](../docs/RE-METHODOLOGY.md).
